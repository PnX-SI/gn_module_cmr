Module initié lors de l'atelier développement du workshop GeoNature (24 et 25 septembre 2018).

⚠️ 2023 : Il a été retenu d'intégrer le concept d'individus dans le module Monitoring plutôt que de le dupliquer en grande partie dans un module spécifique CMR : https://github.com/PnX-SI/gn_module_monitoring/issues/213.  
Ce module est donc archivé.

Installer le module 
------------------

Se placer dans le répertoire backend de GeoNature et activer le virtualenv

``source venv/bin/activate``

Lancer la commande d'installation

``geonature install_gn_module /home/<MON_CHEMIN_ABSOLUE_VERS_LE_MODULE/ /cmr``
